## Technical Implementation

### Backend Endpoints Created

**1. `/api/dashboard/<user_id>` (GET)**
```
Returns: Weekly summary, limits, usage percentages, monthly totals
Used by: Dashboard stats display
```

**2. `/api/chart-data/<user_id>` (GET)**
```
Returns: 
- 7-day date array
- Cumulative energy/water data
- Limit values
- Projected end dates
- Days remaining
- Resource exhaustion details
Used by: Chart rendering and alerts
```

### Frontend Implementation

**Chart Library**: Chart.js (via CDN)
```html
<script src="https://cdn.jsdelivr.net/npm/chart.js"></script>
```

**Canvas Elements**:
```html
<canvas id="energyChart"></canvas>  <!-- Energy line chart -->
<canvas id="waterChart"></canvas>   <!-- Water line chart -->
```

**JavaScript Functions**:
```javascript
loadCharts()                    // Fetch data from API
renderEnhancedCharts()          // Create Chart.js line charts
renderResourceEndDateAlerts()   // Display color-coded alerts
```

## Key Features

### Auto-Updating Charts
- Charts automatically update when you add new entries
- No page refresh needed
- Projections recalculate instantly
- Alert status updates in real-time

### Interactive Tooltips
Hover over any point on the chart to see:
- Exact date
- Exact consumption value
- Distance from limit

### Responsive Design
- Works on desktop, tablet, mobile
- Charts scale with container
- Touch-friendly on mobile devices

### Smart Calculations
```
Daily Average = Total Consumption ÷ 7 days
Remaining = Weekly Limit - Current Usage
Days Until Exhaustion = Remaining ÷ Daily Average
Projected End Date = Today + Days Until Exhaustion
```

## How It Works - User Flow

1. **User Logs In**
   - Dashboard loads
   - Calls `/api/dashboard/<user_id>`

2. **Charts Initialize**
   - Calls `/api/chart-data/<user_id>`
   - Receives 7-day data and projections

3. **Charts Render**
   - Energy chart displays with blue line and red limit line
   - Water chart displays with green line and red limit line
   - Alert cards show status and projected end dates

4. **User Adds Entry**
   - Submits new energy or water reading
   - Dashboard refreshes
   - Charts update automatically
   - Projections recalculate

5. **Real-Time Monitoring**
   - User can hover over points for details
   - Color-coded alerts show resource status
   - Days remaining updates with each entry

## Example Data Flow

### Week View:
```
Day 1: 10 kWh  (Total: 10, Limit: 100, Remaining: 90)
Day 2: 12 kWh  (Total: 22, Limit: 100, Remaining: 78)
Day 3: 11 kWh  (Total: 33, Limit: 100, Remaining: 67)
Day 4: 13 kWh  (Total: 46, Limit: 100, Remaining: 54)
Day 5: 12 kWh  (Total: 58, Limit: 100, Remaining: 42)
Day 6: 14 kWh  (Total: 72, Limit: 100, Remaining: 28)
Day 7: 11 kWh  (Total: 83, Limit: 100, Remaining: 17)

Daily Average: 83 ÷ 7 = 11.86 kWh/day
Days Remaining: 17 ÷ 11.86 = 1.43 days
Projected End: Today + 1.43 days = Tomorrow afternoon
Alert Status: 🟠 URGENT (between 1-3 days)
```
